# Client Portal — Mini Web App

Mini Web App i lidhur me **ErionNezhaBot** në Telegram — portali privat i
klientit.

**Bot:** https://t.me/ErionNezhaBot

## Çfarë është

Faqe e lehtë web (vetëm `index.html` + `img/`) që punon si portal klienti
brenda Telegram-it, e lidhur me @ErionNezhaBot.

## Struktura

```
index.html   — aplikacioni
img/         — asset-et
```
